# RX DECK — Improved Bio / Landing Page

Standalone HTML/CSS/JS landing page for RX DECK, an AI Presentation Studio concept.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive cinematic UI, gradients, VFX
- `script.js` — scroll reveal, cursor glow, magnetic buttons, tilt, progress bar

## Run
Open `index.html` in a browser. No build step is required.

## Notes
- The page is UI/brand presentation only. Backend/API integrations are intentionally not included.
- Google Fonts are loaded from the web; the page still renders with system fallbacks if unavailable.


## Real Website Link
When the real RX DECK website is ready, open `script.js` and replace:
`const REAL_WEBSITE_URL = "YOUR_REAL_WEBSITE_URL";`
with your actual website URL. The Bangla "ওয়েবসাইটে যাও" button will then point there.
